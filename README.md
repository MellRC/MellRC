### ● SIDE A — A-side singles
<a href="https://github.com/MellRC/cursor-cn"><img src="https://raw.githubusercontent.com/MellRC/MellRC/main/assets/cursor-cassette.svg" width="100%" alt="Track 01: cursor-cn. Open the project." /></a>

#### [cursor-cn · Cursor Chinese localization](https://github.com/MellRC/cursor-cn)

Let the tool speak a familiar language, so attention stays on the work.

A Chinese interface pack for Cursor. It localizes the editor and agent UI, covering settings, menus, and common prompts.

<p>
<a href="https://github.com/MellRC/cursor-cn"><img src="https://img.shields.io/badge/%E2%96%B6%20OPEN%20PROJECT-e63329?style=for-the-badge&labelColor=111111" alt="▶ OPEN PROJECT" /></a>&nbsp;

<details>
<summary><b>＋ Open the case · project notes</b></summary>

<br/>

**What is this track for?**

Cut language friction when using the tool, and make the interface easier to read.

**What is on the tape?**

- Chinese localization for the editor and agent UI.
- Translations for Cursor-specific settings and everyday copy.
- Entry points for Windows, macOS, and Linux.

**Where to start?**

Read the [usage notes](https://github.com/MellRC/cursor-cn#如何使用). Version changes and compatibility follow the latest project docs.

</details>
